## Remember the current limits

The system is **not yet complete**. The browser only shows a connection-status page. Some schedule and task operations work behind the scenes, but their changes disappear when the server restarts. Real login, the main user screens, communication cards and progress views are still pending.

For diagrams, separate **planned behavior** from **working features**. For the paper, separate **project goals** from **findings supported by actual study data**.

## What to send

Each team package contains this file, its own guide, and the three shared references above. Extract the ZIP before opening the PDFs. The leader can review both packages.

The original editable documents are also available in docs as Markdown (.md) files. Ask the development team for source-code access if you need to check implementation details.
