# Research Team Guide

**Starting basis for your paper · November 15, 2026**

The project aims to help caregivers, occupational therapists and SPED teachers organize children's routines. Children are intended to follow visual schedules, mark tasks done and communicate using picture cards. These are the project's goals; the full system is still being built.

## What you can start writing

Follow your instructor's required paper format.

| Part of the paper | Where to start |
| --- | --- |
| Introduction and objectives | Use SRS sections 1–2 for the purpose and intended users. Support claims about users' needs with literature or collected evidence. |
| Scope and limitations | Use SRS section 3 and the handoff. Explain what is planned, excluded or unfinished. |
| System description | Use the handoff for the design, main parts and database. Ask the SRS team for its diagrams. |
| Research method | Use SRS sections 8–9 as starting ideas for evaluation. Confirm the research questions, participants, tools and procedures with the instructor. |
| Results and conclusions | Write these after collecting and analyzing the required evidence. |

## Facts you should keep clear

- The browser currently shows only a connection-status page.
- Some schedule/task operations work behind the scenes, using temporary data that disappears on restart.
- Real login, the main Staff and Child screens, picture-card communication and progress views are pending.
- Demo children are sample records, not research participants.
- Passing software tests does not prove that the system is easy to use or improves children's development. The project documents contain no completed user-study results.

## Your next steps

1. Read [SRS.pdf](SRS.pdf) and [DEVELOPMENT_HANDOFF.pdf](DEVELOPMENT_HANDOFF.pdf).
2. Draft the purpose, intended users, scope and limitations. Find and cite relevant literature.
3. Agree on research questions, participants, permissions, evaluation tasks and analysis with the instructor. Confirm which features will be ready to test.
4. Gather actual data before reporting findings. Goals and target scores are not results.

Use [DEVELOPMENT_TEAM_REPORT.pdf](DEVELOPMENT_TEAM_REPORT.pdf) when checking whether a feature exists. The Research team remains responsible for the literature, study and final paper.
