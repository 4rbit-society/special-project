# Araw UI Asset Kit

Included folders:
- `svg/`: Scalable vector assets with transparent backgrounds, grouped by UI category.
- `png-2x/`: High-DPI transparent PNG exports of every vector asset.
- `raster/`: High-resolution illustrated wallpapers, hero banners, and character portraits.
- `tokens/`: CSS custom properties (`araw-tokens.css`) and JSON design tokens (`araw-tokens.json`).
